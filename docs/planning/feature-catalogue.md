# Feature Catalogue

This catalogue records scope without turning every idea into a commitment.

This file answers **when**, at a release-scope level. The
[Future Product Blueprint](../future/README.md) explains **what and why** for
later capabilities, including workflows, rules, dependencies, and MVP design
seams.

Legend:

- **Pilot:** Required for founder simulation and the first safe organic beta
- **Commercial v1:** Expected before broad paid launch
- **Later:** Intentionally deferred
- **Research:** Needs validation before placement

Documentation depth is independent of delivery stage: a Later feature may have
a detailed capability brief while remaining explicitly excluded from the MVP.

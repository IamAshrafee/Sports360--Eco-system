# Product Glossary

Use these meanings consistently in product, design, and engineering documents.

| Term | Meaning |
|---|---|
| Platform | The complete multi-tenant SaaS operated by us |
| Business | A tenant and paying venue organization |
| Venue | One physical business location; may be displayed as Branch |
| Activity | What the customer does, including a sport, training, or event |
| Resource | Physical space/asset whose time availability must be reserved |
| Offering | The way a resource is sold for an activity under booking rules |
| Amenity | Descriptive facility feature that normally does not reserve capacity |
| Add-on | Optional or required product/service attached to a booking |
| Slot | A selectable time interval generated from availability rules |
| Hold | Temporary availability reservation during checkout |
| Booking | Commercial reservation of an offering on a resource |
| Block | Time-based resource unavailability not caused by a customer booking |
| Operational day | Reporting day determined by venue timezone and cutoff |
| User | Global authenticated identity |
| Business Membership | A user's employee/owner relationship with a business |
| Access Profile | Curated set of permissions |
| Venue Scope | Locations to which a membership's access applies |
| Business Customer | Tenant-local relationship with an individual/organization |
| Guest Customer | Customer record not yet linked to a registered user |
| Booking Contact | Person responsible for communication about a booking |
| Team Organizer | Team-scoped responsibility, not a business role |
| Price Snapshot | Booking-time preserved commercial calculation |
| Payment Attempt | Initiated electronic transaction not yet verified successful |
| Payment | Verified or manually recorded collected money |
| Refund | Money returned with reference to an original payment |
| Reversal | Audited correction of an incorrect financial record |
| Settlement | Money transferred by a provider to the merchant |
| Due | Current unpaid booking balance |
| Overdue | Due balance whose actual payment deadline has passed |
| Reserved Occupancy | Reserved minutes divided by available capacity |
| Played Utilization | Completed playing minutes divided by available capacity |
| Entitlement | Plan-controlled feature or usage limit |
| Private Pilot | Restricted live test with assisted venue partners |
| Commercial v1 | First broadly offered paid release after pilot validation |
| Product Horizon | Outcome-based stage indicating when a capability may become valuable; not a promised date |
| Capability Brief | Future-product description of value, actors, workflows, rules, dependencies, seams, and validation trigger |
| Delivery Specification | Implementation-near stories, acceptance criteria, UI, data, failure, security, and rollout detail |
